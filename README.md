# 정철호 × 이종원 BL 단편

성인 대상의 고수위 BL 단편입니다.

## GitHub Pages로 배포하는 방법

1. 이 폴더 전체를 새 GitHub 저장소에 업로드
2. 저장소 Settings → Pages
3. Source를 **Deploy from a branch**로 설정
4. Branch를 `main` (또는 `master`) / `/ (root)`로 선택 후 Save
5. 1~2분 후 `https://[너의아이디].github.io/[저장소이름]/` 주소로 접속 가능

## 주의사항

- 성인 콘텐츠이므로 공개 저장소로 올릴 경우 주의하세요.
- GitHub 이용약관을 위반하지 않는 선에서 사용하세요.
